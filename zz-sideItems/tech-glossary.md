# Tech Glossary

An alphabetical reference for technical terms used throughout the project.

## S

### SEO (Search Engine Optimization)

The practice of improving a website so search engines such as Google and Bing can understand, index, and display it in relevant search results.

SEO commonly includes clear page titles and descriptions, useful content, semantic HTML, fast loading times, mobile-friendly design, descriptive URLs, and accessible page structure. It is especially important for public-facing websites, but usually less important for private applications behind a login.

**Example:** A bakery website can use SEO to improve its chances of appearing when someone searches for “bakery near me.”
